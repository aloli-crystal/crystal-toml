== v0.1.0 — 2026-04-28

First public release of `crystal-toml`. Pure-Crystal TOML v1.0
parser and serializer, with comment-and-formatting preservation
across `parse → modify → write` round-trips.

Public API
----------

* `TOML.parse(string) : TOML::Document` — parse to a rich AST that
  preserves comments, blank lines, and the original byte-level
  formatting. Round-trips byte-identical for unmodified input.
* `TOML.parse_to_hash(string) : Hash(String, TOML::Type)` —
  drop-in replacement for `crystal-community/TOML.cr`. Discards
  trivia, returns a plain hash.
* `Document` typed lookup: `#string?`, `#int?`, `#float?`,
  `#bool?`, `#datetime?`, `#time_of_day?` (and raise-on-missing
  variants without `?`), `#has_key?`, `#get?`, `#get`.
* `Document` editing: `#set(key, value)`,
  `#set_with_comment(key, value, comment)`, `#delete(key)` —
  preserves the surrounding line formatting on update.

Conformance
-----------

**Full conformance with TOML v1.0** as measured by the official
`toml-lang/toml-test` v2.1.0 interop suite:

* Valid tests   : **205 / 205** (100%)
* Invalid tests : **473 / 473** (100%)
* Overall      : **678 / 678** (100%)

The decoder binary `bin/crystal-toml-decoder` is built as part of
the shard's CI and is run against the suite on every push to the
`production` branch.

See `CRYSTAL-TOML-SPECS.adoc` (sibling repo `prod-crystal/`) for the
full specification.
